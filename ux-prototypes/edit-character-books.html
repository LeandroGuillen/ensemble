Books × Edit Character Three single-source navigation ideas

Possibility A · Lowest disruption

Make the tabs themselves editable

A book tab means both “this character belongs to this book” and “this book has a page.” Remove from the tab; add from the + menu. The sidebar can disappear.

Possibility B · Most explicit

Use one persistent book rail

Each row has two clear targets: click the title to open that page; click the checkbox to include or exclude the character. This scales better when a series has many books.

Best for long series

Possibility C · Quietest canvas

Collapse books into a context menu

The editor only shows the current page and a single “Books & pages” control. Opening it reveals every book with membership and navigation actions together.
