Ensemble

Your characters, in files you own.

Ensemble is a desktop app for writers and worldbuilders to keep their characters, houses, places and plots in plain Markdown files they own.

Download for Linux View on GitHub

Linux first, by design.

Why Ensemble

One folder on your disk

Ensemble keeps your cast, your world and your plot in one folder of Markdown files on your own disk. Open that folder in any editor, back it up with the tools you already use, and keep it in Git if you want.

No account, no telemetry

There is no account to create and no server to sign in to. No login, no telemetry, no analytics and no crash reporting.

Plays well with other editors

Files changed in Obsidian or another editor refresh in Ensemble, and the character and House editors ask you to reload from disk before saving over a file that changed outside the app.

Features

People

  • Characters

    Create, edit and organize character profiles with categories and tags.

  • Aliases

    Give a character a.k.a. names and find them from search.

  • Portraits and styles

    Keep one portrait per character style and switch the style from the page.

  • Book pages

    Give a character their own description, tags and picture in each book.

  • Lore figures

    Keep founders, ancestors and legends as name-only records, labelled Lore in pickers.

  • Drawer

    Write a character as a draft and convert it to a Character or a Lore figure later.

  • Casts

    Group characters into a cast and pin them on a pinboard with labelled connections.

  • Names

    Keep name lists with descriptions, comments and strikethrough for options you dropped.

  • Concepts

    Keep titled notes for ideas that are not characters yet.

World

  • Locations

    Record places with one of nine types, such as Country, Settlement, Building or Natural Feature.

  • Houses

    Record crests, mottos, colors, seats, members and an ordered list of reigns with joint heads.

Story

  • Books

    Group your work in books, each with a cover, a status, a plan file and a manuscript folder.

  • Book plan

    Outline phases, chapters and scenes from chapter headings like ## 2180 - Title, with a point-of-view portrait, TODO and OJO counts and a focus mode for one chapter.

  • Plot board

    Lay plot threads out in a grid of rows and move between cells with the keyboard.

Comfort

  • Markdown editor

    Write in a CodeMirror editor with live preview, GFM tables and formatting shortcuts.

  • Wikilinks

    Link characters, locations and Houses with [[Name]], complete them with [[, follow them with Ctrl/Cmd + click, and open a missing target as a new record. The Mentioned in panel on each record lists every place that links to it.

  • Prompts

    Keep image and text prompts as Markdown files. Each file can hold several variants, with notes and the images they produced, and you can link them to characters and locations.

  • Command palette

    Press Ctrl+P or / to search commands.

  • Themes and skins

    7 color themes: Blue Gold, Catppuccin Mocha, Grayscale, Gruvbox, Rosé Pine, Sepia and Tokyo Night. Several skins, including Classic, Pixel and Liquid.

  • Multiple projects

    Keep several projects and open a recent one with the keys 1 to 9, or copy a project to start a variant of it.

  • Undoable deletes

    Delete a character, draft, Lore figure, location, House or cast and undo it for 15 seconds, then it goes to the system trash.

  • Backups

    Create a zip snapshot of a project and restore it into a copy, with automatic snapshots before updates and a retention limit.

Try the demo

To look around before you write anything, open the demo project, an invented world called The Lantern Coast. Copy the examples/demo-project folder from the repository somewhere you can write to first, then open the copy. Ensemble writes to a project as soon as it opens it.

Your files stay yours

  • No account, no login, no telemetry, no analytics and no crash reporting.
  • A project is a folder of plain Markdown files (with YAML front matter), a small ensemble.json and your images, on your disk.
  • Installed builds check GitHub Releases for new versions when the app starts, every four hours, and when you choose “Check for updates”. They never download anything by themselves.
  • AI is optional and off by default. Name suggestions use a local model through Ollama or LM Studio. Portraits can use a local server, InvokeAI or ComfyUI. If you choose OpenAI or Gemini for portraits, Ensemble sends the portrait prompt and your API key to that service. Names are never sent to OpenAI or Gemini.
  • With local tools, nothing leaves your computer. The update check and a cloud portrait provider are the only exceptions, and the portrait provider is your choice.

How your data is stored

Create a folder on your disk and open it in Ensemble as a project. Ensemble adds the folders it needs and writes a small ensemble.json with your categories, tags, books and settings.

Download

Ensemble is Linux first, by design. Every release ships an AppImage, a Debian package and an RPM.

Get the files for your distribution from the latest release on GitHub.

    Other files in this release

      Not seeing the files? Open the latest release on GitHub.

      Install

      AppImage

      A single file you run:

      chmod +x Ensemble-VERSION.AppImage
./Ensemble-VERSION.AppImage

      Keep the AppImage in a folder you can write to, so the updater can replace it.

      Debian, Ubuntu and derivatives

      sudo apt install ./ensemble_VERSION_amd64.deb
# or
sudo dpkg -i ensemble_VERSION_amd64.deb

      Fedora, RHEL and derivatives

      sudo dnf install ./ensemble-VERSION.x86_64.rpm
# or
sudo rpm -i ensemble-VERSION.x86_64.rpm

      Replace VERSION with the version in the file name you downloaded.
